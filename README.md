# 🎬 Movie App

A simple fullstack web application built with **React** (frontend) and **Express** (backend).  
It displays a list of movies and lets you view detailed information about each one.

---

## 🚀 Features
- Movie list with title, tagline, and rating
- Responsive design (grid adapts to desktop and mobile)
- Search bar to filter movies by title
- Detailed movie view with release date, runtime, overview, and rating
- Styled UI with dark blue background and light movie cards

---

## 🛠️ Tech Stack
- **Frontend:** React 18, CSS Grid
- **Backend:** Node.js, Express
- **Data:** `movies_metadata.json`

---

## 📦 Installation & Setup

Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/movie-app.git
cd movie-app

Install dependencies:

bash
npm install
▶️ Running the App
Start the backend server
bash
cd server
node server.js
Backend runs on http://localhost:4000

Start the frontend
Open a second terminal in the project root:

bash
npm start
Frontend runs on http://localhost:3000 (or 3001/3002 if 3000 is busy).

📖 Usage
Open the frontend in your browser.

Use the search bar to filter movies.

Click a movie card to view details.

Use the Back to list button to return.
